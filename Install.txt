ZapQ installation
=================

Option 1: release binary (recommended)

  Download the archive for your platform from
  https://github.com/raiyanyahya/zapq/releases, then:

    tar xzf zapq-linux-amd64.tar.gz
    sudo mv zapq-linux-amd64 /usr/local/bin/zapq
    zapq --addr :8080

Option 2: Docker

    docker run --rm -p 8080:8080 ghcr.io/raiyanyahya/zapq:latest

Option 3: build from source (needs Go 1.22+)

    git clone https://github.com/raiyanyahya/zapq.git
    cd zapq
    make build          # or: go build -o zapq .
    ./zapq

Run it as a service

  Use the hardened systemd unit in deploy/systemd/zapq.service:

    sudo cp zapq /usr/local/bin/
    sudo cp deploy/systemd/zapq.service /etc/systemd/system/
    sudo systemctl daemon-reload
    sudo systemctl enable --now zapq
    journalctl -u zapq -f

Verify

    curl localhost:8080/health     # -> ok
    curl -X POST localhost:8080/enqueue -d hello
    curl localhost:8080/dequeue    # -> hello

See ReadMe.md for configuration (auth token, snapshots, metrics, TLS).
